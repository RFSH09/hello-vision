# Data collection protocol (draft)

Recorded by our own team, with consent, on spare (unused) fridges. Data stays in private storage.

Scripted scenarios: take 1, take 2, take and return, take nothing, fast hand, two hands,
occluded, low light. Target counts per SKU: to be set after the first detector baseline
(proposal: at least 30 sessions per SKU, with every look-alike group covered in all scenarios).
Each session is labelled with its true cart and TAKE/RETURN events.
