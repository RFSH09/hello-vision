# Dataset card: synthetic-v0

| Field | Value |
| --- | --- |
| Source | generated by `hello_vision.synth` from drawn placeholder products (no real images) |
| Generator | `tools/gen_synthetic.py` (random scenes), `sim/make_demo.py` (scripted sessions) |
| Labels | boxes (`product`, `hand`), SKU per product box, per-session ground-truth cart and actions |
| Format | COCO JSON + JPEG; sessions as MP4 + `*.truth.json` |
| Reproducibility | seeded; same seed and version give identical frames |
| License | generated data, Apache-2.0 with the code |
| Personal data | none |
| Known limits | flat shapes, one camera angle, six shelf slots, crude hand; says almost nothing about real fridges |

Real datasets (team-recorded sessions, purchase-history weak labels) get their own cards here and live in
private storage behind DVC. See `docs/DATA_COLLECTION.md` and `docs/DVC.md`.
